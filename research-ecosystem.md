## New deep-course direction

**Systems Research Lab** will extend the existing System Fundamentals path into operating-system and distributed-systems depth. Its phases will focus on kernel tracing, virtual memory, filesystem correctness, replication, consensus, observability, and failure testing, using MIT, OSTEP, Cambridge, and Raft materials.

**Compiler & Runtime Architecture** will add a second deep path from language front-end to runtime. Its phases will cover lexing and parsing, intermediate representations, bytecode/VM design, register allocation, garbage collection, JIT concepts, and performance measurement, grounded in Nand2Tetris and official university compiler/architecture notes.

## PDF indexing rules

The UI should store every resource as metadata, not as copied files: title, source institution, author when available, resource type, topic, level, estimated reading time, course relationships, and canonical URL. Only source URLs are embedded; the app does not republish copyrighted PDFs. The reader should use a browser PDF embed with an “open original” and “download if provided by source” fallback.

## Certificate rules

The Rampage completion certificate is an informal digital artifact, not an academic credential, professional license, accreditation, or employment certification. It should clearly state “digital completion record” and “not an accredited credential.” It can be generated locally from the learner’s entered name, course, completion date, and locally generated certificate ID, with no claim of external verification.
