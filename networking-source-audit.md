# Networking Systems Source Audit

## Verified curriculum anchors

1. **University of Massachusetts Amherst / Kurose and Ross online lectures** — the official lecture index covers Computer Networks and the Internet, Application Layer, Transport Layer, Network Layer data and control planes, Link Layer, Wireless and Mobile Networks, and Network Security. It also advertises open knowledge checks and interactive problems. Source: https://gaia.cs.umass.edu/kurose_ross/lectures.php

2. **Stanford CS144** — the Stanford course page describes packet switching, layer architectures, web/HTTP, VoIP, peer-to-peer file sharing, socket programming, TCP/IP reliability, flow and congestion control, names and addresses, routing, Ethernet, switches, wireless networks, and network security. The page links to the course website at https://cs144.github.io/. Source: https://online.stanford.edu/courses/cs144-introduction-computer-networking

3. **Cisco Networking Academy Networking Basics** — the public curriculum lists modules on network types, data transmission, bandwidth and throughput, clients and servers, components, wireless/mobile networks, home networking, communication models, media, Ethernet/access layer, IPv4/IPv6, DHCP, NAT, ARP, routing, TCP/UDP, ports, DNS, web/FTP/email services, and network testing utilities. It states 22 hours and 13 labs for the self-paced course and exposes earned badge categories. Source: https://www.netacad.com/courses/networking-basics?courseLang=en-US

4. **Microsoft Learn Fundamentals of computer networking** — the public module lists six units covering network types/topologies, network devices, network protocols, IP address standards/services, TCP/IP, DNS, ports, and Azure networking mappings. It states 47 minutes and 900 XP for the module. Source: https://learn.microsoft.com/en-us/training/modules/network-fundamentals/

## Design implications

The Networking Systems course should be structured as a beginner-to-operator route with chapters for foundations and models, Ethernet and access, IP addressing and subnetting, ARP/DHCP/NAT, routing, transport protocols and ports, application services, troubleshooting utilities, and wireless/security. Each lesson should link to an original source and use a clearly labeled lab brief. Interactive labs must be course-authored tasks that do not claim a real network execution unless the application actually provides one; where no sandbox exists, they should be evidence-based packet tracing, command interpretation, configuration planning, or source-guided exercises.

## Claim boundaries

Cisco's listed 13 labs and badge names belong to Cisco's own course and must not be presented as Rampage-issued achievements. Rampage can cite the curriculum as a source, create its own clearly labeled learning checkpoints, and award Rampage XP/badges only for server-verified Rampage activity. Stanford's page describes a graduate course with prerequisites and paid enrollment; it should be used as an advanced reference anchor, not represented as a free Rampage video course. Kurose/Ross explicitly notes that some video sections are missing or being updated, so unavailable sections should remain source links or reading-led lessons rather than fabricated embeds.
