# Rampage Research Notes

## Verified source findings

**MIT 6.S081 / Operating System Engineering.** The official MIT Fall 2021 course page describes operating-system design and implementation using xv6 on RISC-V. Its scope includes virtual memory, file systems, threads, context switches, kernels, interrupts, system calls, interprocess communication, coordination, and hardware/software interaction. It explicitly frames the course as learning by doing and uses lab assignments that extend xv6. Source: https://pdos.csail.mit.edu/6.828/2021/overview.html

**Stanford CS144 / Introduction to Computer Networking.** The official Fall 2025 page lists a project sequence of eight checkpoints: networking warmup; stitching substrings into a byte stream; TCP receiver; TCP sender; measuring the real world; network interface; IP router; and an Internet-plus-creative-project checkpoint. It also lists lecture notes on datagrams, reliability, TCP, congestion control, routing, elastic buffers, and Internet security. Source: https://cs144.github.io/

**Nand2Tetris.** The official project page states that the journey spans 12 projects in two parts, with project guidelines and lecture slides. Part I covers Boolean Logic, Boolean Arithmetic, Memory, Machine Language, Computer Architecture, and Assembler. Part II covers VM, high-level language, parsing, code generation, and operating system work. Source: https://www.nand2tetris.org/course

## Product implications

Rampage should be a resource-centered academy, not only a course catalog. The scalable content model should support courses, phases, chapters, lessons, videos, labs, books, repositories, project briefs, and external links. The first spotlight course is System Fundamentals, but the shell must also expose additional courses such as Computer Networking, AI Systems, and Web Foundations as data-driven catalog entries.

## Source caveat

The MIT page is a Fall 2021 course page with an official page timestamp updated in 2025. Stanford CS144 is the Fall 2025 page. The interface should show source year/version labels rather than implying that all materials are current in 2026.


**MIT 6.5840 / Distributed Systems, Spring 2026.** The current official page describes a graduate course built around lectures, readings, programming labs, an optional project, and examinations. Its major topics are fault tolerance, replication, and consistency, with case studies of distributed systems. The page exposes five lab links and notes substantial programming experience as helpful. Source: https://pdos.csail.mit.edu/6.824/

**Berkeley CS61C.** Research surfaced the official current course page at https://cs61c.org/ and official YouTube lecture examples including RISC-V introduction at https://www.youtube.com/watch?v=w7efr8-MRPQ and RISC-V calling conventions at https://www.youtube.com/watch?v=1jplJRDB0TI. These are suitable for the architecture/resource library layer, with source year labels.

**MIT Missing Semester.** The official site is https://missing.csail.mit.edu/ and the current 2026 shell lecture page is https://missing.csail.mit.edu/2026/course-shell/. The course is described as nine one-hour lectures focused on practical computing tools, including the command line, editors, version control, profiling, debugging, data wrangling, and security.
